<h1 align="center">📧 Spam Email Detection</h1>

<p align="center">
  A Machine Learning project for detecting <b>Spam</b> and <b>Not Spam (Ham)</b> messages using NLP.
</p>

<hr>

<h2>🚀 Features</h2>

<ul>
  <li>Text preprocessing</li>
  <li>TF-IDF vectorization</li>
  <li>Multiple Machine Learning models</li>
  <li>Model evaluation</li>
  <li>Spam/Ham prediction</li>
</ul>

<h2>🤖 Machine Learning Models</h2>

<ul>
  <li>Naive Bayes</li>
  <li>Support Vector Machine (SVM)</li>
  <li>Ensemble Models</li>
</ul>
